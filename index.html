데이터 백업

구글 연결 시 데이터는 내 구글드라이브(앱 전용 공간)에 자동 동기화되어, 같은 계정으로 연결한 모든 기기(핸드폰·노트북·아이패드)에서 공유됩니다.

구글 연동 설정 가이드

무료이며 약 10분 소요됩니다. 노트북에서 진행하세요.

  1. console.cloud.google.com 접속 → 구글 로그인 → 상단에서 새 프로젝트 생성 (이름: 예 my-planner)
  2. 왼쪽 메뉴 API 및 서비스 → 라이브러리에서 Google Calendar API와 Google Drive API를 각각 검색하여 사용 설정
  3. API 및 서비스 → OAuth 동의 화면 → User Type 외부 선택 → 앱 이름·이메일 입력 후 저장 → 테스트 사용자에 본인 지메일 추가
  4. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 애플리케이션 유형: 웹 애플리케이션
  5. 승인된 자바스크립트 원본에 이 플래너를 여는 주소를 추가합니다. (아래 호스팅 안내 참조. 예: https://본인아이디.github.io)
  6. 생성된 클라이언트 ID를 복사하여 설정 화면에 붙여넣고 구글 계정 연결을 누르면 완료!

⚠ 중요: 파일을 직접 열면 구글 연동이 안 됩니다

구글 보안 정책상 file://로 연 페이지에서는 로그인이 차단됩니다. 함께 드린 README의 GitHub Pages 호스팅 안내(5분)를 따라 인터넷 주소를 만들면 핸드폰·아이패드·노트북 어디서든 같은 주소로 접속할 수 있습니다. 구글 연동 없이 쓰실 경우에는 파일을 그냥 열어도 모든 기능(우선업무·일정·기록·월간표)이 동작합니다.
